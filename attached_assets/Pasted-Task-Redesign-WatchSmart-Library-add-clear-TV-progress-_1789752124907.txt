Task: Redesign WatchSmart Library + add clear TV progress tracking and tutorial feature card

I want the WatchSmart Library redesigned. Please treat this as one complete feature update and do not make unrelated changes elsewhere in the app.

The current Library works, but it is confusing, TV episode tracking is not obvious, watch-time statistics are not clearly visible, and the web/native versions have started to differ.

Important: inspect the existing implementation, backend APIs, watched/reaction system and native/web Library screens before changing anything. Reuse existing functionality wherever possible. Do not create duplicate data models or duplicate endpoints if equivalent functionality already exists.

1. Library overall layout

Keep the existing WatchSmart dark design and orange branding.

At the top:

Library

Keep the large segmented control:

♡ Watchlist | ◉ Watched

It should be immediately obvious which section is selected.

Keep:

All | Movies | TV

and the existing sorting control such as:

Recently added

Make spacing, typography and poster sizes consistent on mobile web and the native app.

⸻

2. Watched tab — new layout

At the top of the Watched tab add a compact statistics panel showing:

* Number of titles watched
* Total watch time
* Number of episodes watched

Example:

3 titles watched | 39h 22m watch time | 47 episodes

These must use real user data, not placeholders.

If the backend already contains enough data to calculate these figures, use it. If not, add the minimum backend calculation needed.

Movies should contribute their runtime.

TV watch time should be calculated from episodes the user has actually logged as watched, not the runtime of the entire series.

⸻

3. Continue Watching

Create a clear Continue watching section for TV programmes that have started but are not completed.

Each card should contain:

* Poster
* Title
* Current season/episode
* Episodes watched / episodes available where known
* Progress percentage
* Orange progress bar
* Update progress button
* ••• menu for secondary actions

Example:

Fringe

S1 E6 of 20

[progress bar] 30%

[Update progress] [...]

Do NOT use the current unexplained:

− S1 E1 +

control directly underneath posters.

It is not obvious enough to users what that control does.

⸻

4. Update Progress flow

Pressing Update progress should open a clear modal/bottom sheet.

It should say something similar to:

Update your progress

Season: 1

Episode: 6

Include simple controls to select the season and episode.

Include:

Mark next episode watched

Mark season complete

and, where appropriate:

I’ve finished the series

Saving should immediately update:

* Library progress
* Continue Watching
* episode count
* percentage
* total watch time

Users must also be able to correct progress if they accidentally log too many episodes.

⸻

5. Completed section

Under Continue Watching, create:

Completed

Completed movies and completed TV series should appear here.

Movies should show the user’s existing WatchSmart reaction where available:

❤️ Loved

👍 Liked

😐 Okay

👎 Didn't like

etc.

Also show movie runtime.

Example:

Rocketman

❤️ Loved

2h 1m

TV programmes should only appear as completed when the series/current available content has genuinely been marked completed.

Do not show the same programme unnecessarily in both Continue Watching and Completed.

⸻

6. Watchlist tab

Watchlist should remain much simpler.

Saved titles should display in a clean 2-column grid.

Movies:

* Poster
* title
* runtime where known
* provider
* saved date if available
* Watch now where appropriate

TV:

* poster
* title
* number of seasons where known
* provider
* saved date
* Start tracking

For TV, use Start tracking instead of immediately displaying episode +/- controls.

When Start tracking is pressed, let the user select where they currently are in the programme.

Once tracking has started it moves into/appears within Continue Watching.

⸻

7. Marking a TV programme as Watched elsewhere

Check the Discover/title-detail watched flow.

Currently WatchSmart asks for a reaction when something is marked Watched on the native app.

Keep this behaviour.

For a TV series, do not assume pressing Watched means every episode of every season has been completed.

Ask:

How far have you watched?

Allow season + episode selection.

Also include:

I've finished the series

Then ask/use the existing reaction system.

Do not create a second reaction system.

⸻

Add one additional tutorial poster/card explaining this Library feature.

Do NOT create another popup tutorial later in the Library.

Tutorial card:

Track every episode 📺

Keep up with your TV shows, log the season and episode you’re on, and WatchSmart will track your progress and total watch time.

Visually demonstrate:
