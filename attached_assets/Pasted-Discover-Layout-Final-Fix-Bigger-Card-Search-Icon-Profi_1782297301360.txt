Discover Layout Final Fix — Bigger Card, Search Icon, Profile in Bottom Nav

Problem

The Discover screen is still getting messy because too many elements are competing for space at the top.

Current issues:

* Greeting wastes vertical space.
* Profile avatar / orange “R” is too visually loud.
* Header pushes the recommendation card down.
* Action buttons feel separate from the card.
* Card should be bigger and more cinematic.
* Search is useful, but it should not be a full search bar.

The Discover screen should be built around one thing:

Show me one great recommendation and let me act quickly.

⸻

Final Navigation Decision

Move Profile into the bottom navigation.

Bottom nav should be exactly:

1. Discover
2. Watchlist
3. Friends
4. Savings
5. Profile

Remove Profile/avatar from the top header completely.

Profile page should contain account/settings, with Sign Out at the very bottom.

⸻

Final Header Decision

Discover header should be extremely simple.

Header layout

Left:

Discover

Right:

Search icon

Optional:

* Filter icon only if filters already exist and are needed.

Do not show:

* WatchSmart logo
* Good morning greeting
* “What are we watching tonight?”
* Profile avatar
* notification icon
* large orange initial circle

Header style

* Compact height
* Large bold “Discover”
* Search icon top-right
* Dark circular icon button
* Subtle border
* Orange hover/active state

The header should not be the main visual focus.

The movie card is the hero.

⸻

Search Behaviour

Search should be a top-right icon, not a permanent search bar.

Reason:
Search is useful, but the primary app behaviour is swiping.

A full search bar takes too much vertical space.

When tapping search icon

Open existing search flow or create a dedicated Search screen/modal.

Search screen should support:

* movies
* TV shows
* actors
* directors
* genres/keywords if available

Search placeholder:

Search movies, shows, actors…

Search as Recommendation Signal

Search is not just navigation. It is intent data.

Track search-related events where possible:

* searched_title
* searched_actor
* searched_director
* searched_keyword
* searched_then_saved
* searched_then_watched
* searched_then_added_to_watchlist

If analytics support is not ready, leave clear TODO comments.

These signals can later help recommendations.

⸻

Discover Tabs

Tabs should remain:

* For You
* Movies
* TV Shows
* New

Do not use:

* Trending
* Upcoming

Tabs should be compact and sit directly under the header.

⸻

Bigger Recommendation Card

Use the space saved from removing the greeting/profile/banner to make the card bigger.

Card requirements

* Card should start close under the tabs.
* Card should be wider and taller.
* Use most of the available viewport.
* Keep cinematic poster/backdrop focus.
* Rounded corners.
* Dark gradient overlay.
* Title must be dominant.
* Content must not feel cramped.

Target:
The card should occupy the majority of the visible screen.

Do not let the header or metadata steal focus from the card.

⸻

Floating Action Buttons Overlapping Card

The action buttons should overlap the bottom edge of the card.

They should not sit as a detached row below the card.

Required buttons

* Rewind
* Skip
* Watched
* Save

No separate Undo button.

Rewind uses undo/reverse logic behind the scenes.

Position

Buttons should:

* float over the bottom part of the card
* overlap the card edge by roughly 30–40%
* have a clear shadow/elevation
* remain visually connected to the card
* not be hidden below the fold
* not overlap the bottom nav

Visual style

Circular premium buttons:

Rewind:

* dark button
* orange outline/icon

Skip:

* dark button
* muted/red icon

Watched:

* dark button
* green icon

Save:

* dark button
* orange icon

Labels can be small underneath icons if space allows.

If labels make the screen messy, use icons only with accessible aria labels.

⸻

* Discover
* Watchlist

Style

* fixed bottom

* subtle top border

It should not compete with the card.

Sign Out

Sign Out must be at the very bottom of the Profile page.

Style:

* red text

Do not show Sign Out anywhere in the bottom nav.
