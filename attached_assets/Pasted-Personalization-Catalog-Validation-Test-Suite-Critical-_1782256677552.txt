Personalization & Catalog Validation Test Suite (Critical Before Public Growth)

Objective

We have made significant improvements to:

* Catalog eligibility
* Recommendation ranking
* Discovery logic
* Taste profiles
* Save/skip learning
* Provider filtering
* Quality scoring

However, we currently have a major unanswered question:

Is the system actually becoming better for users over time?

The goal of this project is to prove that:

1. New users receive increasingly relevant recommendations.
2. The catalog quality remains high.
3. Personalization becomes stronger as more interactions occur.
4. Discovery remains relevant without becoming random.
5. Old/low-quality titles are not leaking into the feed.
6. The system is learning from behaviour rather than simply collecting data.

This project should create measurable evidence that recommendation quality improves over time.

Success Criteria

The project passes only if all of the following are true:

✓ Catalog is predominantly modern and high quality.

✓ Old-title leakage is explained and controlled.

✓ Save rates improve after learning begins.

✓ Skip rates decrease over time.

✓ Discovery remains adjacent to user tastes.

✓ Behaviour-based ranking overtakes onboarding-based ranking.

✓ Active users receive noticeably different feeds from one another.

✓ Recommendation explanations clearly reflect learned preferences.

✓ Personalization improves between 25 and 100+ interactions.

✓ We can prove with data that the engine is becoming better for individual users.

⸻

Final Deliverable

Produce a Recommendation Health Report showing:

* Catalog quality score
* Discovery quality score
* Personalization score
* Learning effectiveness score
* Fallback dependency score
* Top recommendation issues
* Suggested ranking improvements

The report should allow us to confidently answer:

“Is WatchSmart genuinely learning from users and improving recommendations over time?”

with measurable evidence rather than assumptions.
